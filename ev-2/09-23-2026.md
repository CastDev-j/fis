- Se apoya en la **matriz de trazabilidad** (requerimiento -> diseno -> codigo -> prueba).

#### Análisis

- Yo, cliente, quiero un programa que calcule el volumen de una esfera dado su radio.
- Yo, cliente, quiero un programa que calcule el volumen de un prisma dado el área de su base y su altura.
- Yo, cliente, quiero un programa que calcule el volumen de una pirámide dado el área de su base y su altura.
- El programa debe usar las fórmulas correctas según la figura.

#### Diseño

Funcionalidades necesarias:
- Función que calcule el volumen de una esfera con su radio.
- Función que calcule el volumen de un prisma con el área de la base y la altura.
- Función que calcule el volumen de una pirámide con el área de la base y la altura.

Fórmulas:

```
V esfera  = (4/3) * PI * r^3
V prisma  = areaBase * altura
V piramide = (areaBase * altura) / 3
```

Flujo:

![[Pasted image 20260923121542.png]]

Algoritmo:

```
function volumenEsfera(radio):
    return (4/3) * PI * radio^3

function volumenPrisma(areaBase, altura):
    return areaBase * altura

function volumenPiramide(areaBase, altura):
    return (areaBase * altura) / 3

// Flujo principal
console.log(volumenEsfera(3))
console.log(volumenPrisma(10, 5))
console.log(volumenPiramide(12, 6))
```

#### Construcción y Pruebas

Todo el proceso de construcción y pruebas está dentro de la carpeta `practica-estimacion/`, con una implementación por algoritmo en:

- `lib/esfera.ts` -> `volumenEsfera`
- `lib/prisma.ts` -> `volumenPrisma`
- `lib/piramide.ts` -> `volumenPiramide`

Desde `index.ts` se importan las tres funciones y se ejecuta con `pnpm run dev` mostrando los volúmenes calculados.
