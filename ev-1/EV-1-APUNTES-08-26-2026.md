## Conceptos base 
### Que es la ingenieria de software

Es la disciplina que se centra en diseñar, construir sistemas complejos, manteniendo un orden
producir sistemas que satisfagan las necesidades del usuario

### Que es software

Conjunto de instrucciones (programas), datos y documentación que hacen funcionar un computador. Es intangible, no se desgasta y es modificable. Se clasifica en: sistema (SO, controladores), aplicación (para el usuario) y desarrollo (compiladores, IDEs).

### Proceso de software

Conjunto de actividades, métodos y herramientas para desarrollar software: planeación, análisis, diseño, implementación, pruebas y mantenimiento. Define cómo se construye el producto.

### Proceso 

Secuencia de pasos concretos que sigue un equipo para entregar software (p. ej. modelos en cascada, ágil, iterativo). Es la ejecución práctica del proceso de software.

### Producto de software

Resultado entregable del proceso: el programa funcional, su documentación y los datos asociados. Debe cumplir requisitos, calidad y ser útil para el cliente y el usuario.

### Cliente y usuario

El **cliente** paga, encarga y define requisitos de alto nivel; el **usuario** usa el sistema y da retroalimentación real. El cliente busca rentabilidad y plazos; el usuario prioriza usabilidad. Un buen diseño equilibra ambos, enfocándose en la experiencia del usuario.

### Stakeholders

Cualquier persona u organización con interés o impacto en el proyecto: cliente, usuario, equipo de desarrollo, patrocinadores, gerencia y reguladores. Identificarlos e involucrarlos es clave para alinear requisitos y asegurar el éxito del software.
